# Smyrna White 8U All-Stars — Deploy Guide

## What's in this folder
- `index.html` — the full team dashboard (this is the actual website)
- `vercel.json` — tells Vercel how to host it
- `README.md` — this file

---

## How to get this live in 10 minutes

### Step 1 — Create a free GitHub account
Go to https://github.com and sign up. It's free.

### Step 2 — Create a new repository
1. Click the **+** button in the top right → **New repository**
2. Name it: `smyrna-white-8u`
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload the files
1. On your new repository page, click **Add file** → **Upload files**
2. Drag both `index.html` and `vercel.json` into the upload area
3. Click **Commit changes**

### Step 4 — Deploy on Vercel
1. Go to https://vercel.com and click **Sign up**
2. Choose **Continue with GitHub** — it links automatically
3. Click **Add New Project**
4. Find `smyrna-white-8u` in the list and click **Import**
5. Click **Deploy** (don't change any settings)

### Step 5 — You're live!
Vercel gives you a URL like:
`https://smyrna-white-8u.vercel.app`

Share that link with every parent. They can bookmark it on their phone's home screen.
